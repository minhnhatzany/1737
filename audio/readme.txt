Thư mục nhạc nền
================

Hãy đặt đúng 3 file (MP3 hoặc định dạng trình duyệt hỗ trợ) với tên:

  bgm1.mp3
  bgm2.mp3
  bgm3.mp3

Game sẽ tự chuyển bài khi hết track. Nếu thiếu file, trình duyệt có thể báo lỗi tải âm thanh — bạn có thể tắt nhạc trong Cài đặt (răng cưa góc màn hình).
